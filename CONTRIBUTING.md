# Contributing

Contributions that improve reproducibility, identify hardware errors, improve non-commercial firmware/software, or add validation data are welcome.

Please follow these rules:

1. **Do not rename a board revision as a platform version.** `Platform V2` is the system generation; `MB-R2.1`, `OFS-R2.1.1`, etc. are daughterboard revisions.
2. State which exact PCB revision and firmware commit you tested.
3. For hardware changes, include the editable KiCad source as well as fabrication exports when practical.
4. Separate measured results from estimates, simulations, and design targets.
5. Do not claim an untested board or algorithm is validated.
6. Do not commit KiCad lock files, `.history/`, `*-backups/`, or personal editor state.
7. By contributing, you confirm that you have the right to submit the contribution and that it may be distributed under the applicable non-commercial repository licence.

For commercial licensing or a commercial collaboration, use the route described in `COMMERCIAL_LICENSING.md` rather than a normal pull request.
